## Как читать таблицы

Главным всегда считается **каноническое русское название из локализации
игры**. Короткий код в обратных кавычках — например, `pikeman` или `ruscen` —
это внутренний идентификатор объекта. Он нужен только для точного различения
похожих вариантов и поиска по файлам игры.

В компактных таблицах используются сокращения ресурсов:
**Е** — еда, **Д** — дерево, **К** — камень, **З** — золото,
**Ж** — железо, **У** — уголь. «Игровая секунда» означает время внутри
симуляции; на скорости «Быстро» одна игровая секунда проходит примерно за
0,71 реальной секунды.
