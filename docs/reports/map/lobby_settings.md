# Настройки матча

[← Таблицы и расчёты](../README.md)

Канонические русские названия всех параметров лобби и краткое описание
их действия. Внутренний номер нужен только для сопоставления с реплеями
и файлами игры; английское название показано вторым.

Подробное объяснение скрытого поведения находится в статье
[«Как настройки влияют на игру»](../../recon/world/map/game_settings.md).

## Карта и природные ресурсы

### Размер карты (`mapsize`)

| Значение | Размер, тайлы | Русское название | Английское название |
| :---: | --- | --- | --- |
| 0 | 320 | Стандартная | Standard |
| 1 | 480 | Большая | Big |
| 2 | 640 | Огромная | Huge |
| 3 | 256 | Маленькая | Tiny |

Карта всегда квадратная; размер в тайлах задан непосредственно игрой [^1].

### Тип ландшафта и воды (`terraintype`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | Суша | Land |
| 1 | Средиземное море | Mediterranean |
| 2 | Полуострова | Peninsulas |
| 3 | Острова | Islands |
| 4 | Континенты | Several Continents |
| 5 | Континент | Single Continent |
| 6 | Озера | Lakes |
| 7 | Берег | Coast |
| 8 | Реки | Rivers |
| 9 | Без воды | Without water |

На полуостровах, островах и континентах есть морская вода, доступ к которой требует порта [^2].

### Рельеф (`relieftype`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | Равнина | Plain |
| 1 | Холмы | Low Mountains |
| 2 | Горы | High Mountains |
| 3 | Высокогорье | Highlands |
| 4 | Плато | Plateaus |
| 5 | Пустыня | Desert |

По умолчанию `relieftype = 3` («Высокогорье») [^3].

### Стартовые ресурсы (`resourcestart`)

| Значение | На каждый ресурс | Русское название | Английское название |
| :---: | --- | --- | --- |
| 0 | 1000 | Обычные | Normal |
| 1 | 4000 | Богатые | Rich |
| 2 | 5000 | Тысячи | Thousands |
| 3 | 1000000 | Миллионы | Millions |

Еда, дерево, камень, золото, железо и уголь получают одинаковое стартовое количество. По умолчанию = 2 («Тысячи», 5 000 каждого) [^4].

### Количество месторождений (`resourcemines`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | Мало | Poor |
| 1 | Средне | Medium |
| 2 | Много | Rich |

По умолчанию `resourcemines = 1` («Средне») [^5]. Конкретные числа шахт за уровень — в [`map_resources.md`](map_resources.md) и в [`recon/world/map/map_generation_pipeline.md`](../../recon/world/map/map_generation_pipeline.md).

### Сезон (`season`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | Лето | Summer |
| 1 | Осень | Autumn |
| 2 | Зима | Winter |
| 3 | Пустыня | Desert |

Вариант «Пустыня» использует отдельный набор пустынных лесов и камней [^6].

## Правила партии

<a id="startingunits--стартовая-армия"></a>
### Стартовая армия (`startingunits`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Армия | Army |
| 2 | Большая армия | Big Army |
| 3 | Огромная армия | Huge Army |
| 4 | Множество крестьян | Army of Peasants |
| 5 | Разные нации | Different Nations |
| 6 | Башни | Towers |
| 7 | Пушки | Cannons |
| 8 | Пушки и гаубицы | Cannons and Howitzers |
| 9 | Казармы 18 века | 18th Century Barracks |
| 10 | Казарма 17 в. | Barrack17 |
| 11 | Деревня | Village |
| 12 | Срубы | Logcabins |
| 13 | Уния | Union |

> Независимо от выбора игрок получает **18 крестьян** сеткой 6×3 вокруг стартовой точки [^7].

### Монгольфьеры (`balloon`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Без монгольфьеров | No Balloons |
| 2 | Монгольфьеры | Balloons |

Монгольфьер — особый юнит, открывающий обзор на большой высоте.

### Пушки, башни и стены (`cannons`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Без пушек, башен и стен | No Cannons, Towers and Walls |
| 2 | Дорогие пушки | Expensive Cannons |

Опция «Дорогие пушки» поднимает цены пушек через апгрейд — точные множители читать в `country.script` (раздел артиллерийских апгрейдов).

<a id="peacetime--время-мира"></a>
### Время мира (`peacetime`)

| Значение | Минут (игр.) | g-секунд | Русское название | Английское название |
| :---: | --- | --- | --- | --- |
| 0 | 0 | 0 | Без времени мира | No Peace Time |
| 1 | 10 | 600 | 10 мин | 10 min |
| 2 | 20 | 1200 | 20 мин | 20 min |
| 3 | 30 | 1800 | 30 мин | 30 min |
| 4 | 45 | 2700 | 45 мин | 45 min |
| 5 | 60 | 3600 | 60 мин | 60 min |
| 6 | 90 | 5400 | 90 мин | 1.5 hours |
| 7 | 120 | 7200 | 2 часа | 2 hours |
| 8 | 180 | 10800 | 3 часа | 3 hours |
| 9 | 240 | 14400 | 4 часа | 4 hours |
| 11 | 15 | 900 | 15 мин | 15 min |

Минуты — **игровые**. На скорости «Быстро» (×1,4) одна игровая минута = 60 / 1.4 ≈ 42.9 реальных секунд: 10-минутный мир длится примерно 7 реальных минут.

Подробности механики (как движок блокирует поиск врагов, ничейные ячейки, переход от мира к войне) — в [`recon/world/map/game_settings.md`](../../recon/world/map/game_settings.md#peacetime--как-устроен-мир).

### Переход в XVIII век (`century18`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Никогда | Never |
| 2 | Сразу | Immediately |

Для Украины, Турции и Алжира вариант «Сразу» ничего не меняет: эти нации не могут перейти в XVIII век.

<a id="capture--правила-захвата"></a>
### Правила захвата (`capture`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Без захвата крестьян | No Capturing Peasants |
| 2 | Без захвата крестьян и центров | No Capturing Peasants or Centres |
| 3 | Только пушки | Artillery Only |

Геометрия захвата (радиусы, кто захватывается, кто нет) — в [`recon/world/economy/capture_mechanics.md`](../../recon/world/economy/capture_mechanics.md).

<a id="marketdip--рынок-и-дипцентр"></a>
### Рынок и дипломатический центр (`marketdip`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Без дип. центра | Without dip. center |
| 2 | Без рынка | Without market |
| 3 | Не доступны | Without both |
| 4 | Дорогие наёмники | Expensive Mercenaries |

Вариант «Дорогие наёмники» утраивает цену найма. Подробности — в [`recon/systems/mercenaries_diplomacy.md`](../../recon/systems/mercenaries_diplomacy.md).

### Расположение союзников (`teams`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Рядом | Nearby |

При `teams = 1` команда стартует в соседних позициях, а не разбросанной по карте.

### Лимит населения (`limit`)

| Значение | Юнитов | Русское название | Английское название |
| :---: | --- | --- | --- |
| 0 | — | Без ограничения | Without limitation |
| 1 | 500 | 500 юнитов | 500 units |
| 2 | 750 | 750 юнитов | 750 units |
| 3 | 1000 | 1000 юнитов | 1000 units |
| 4 | 1500 | 1500 юнитов | 1500 units |
| 5 | 2200 | 2200 юнитов | 2200 units |
| 6 | 3000 | 3000 юнитов | 3000 units |
| 7 | 5000 | 5000 юнитов | 5000 units |
| 8 | 8000 | 8000 юнитов | 8000 units |

Это общий потолок поверх мест населения, которые дают городские центры, казармы и дома. Потолок никогда не превышается, даже если здания позволяет больше.

<a id="gamespeed--скорость-партии"></a>
### Скорость партии (`gamespeed`)

| Значение | Тиков/реальная секунда | Множитель к норме | Русское название | Английское название |
| :---: | --- | --- | --- | --- |
| 0 | 7 | 0.7 | Медленно | Slow |
| 1 | 10 | 1.0 | Нормально | Normal |
| 2 | 14 | 1.4 | Быстро | Fast |

Одна игровая секунда всегда содержит 32 кадра симуляции; меняется только её длительность в реальном времени.

### Помощник (`adviserassistant`)

| Значение | Русское название | Английское название |
| :---: | --- | --- |
| 0 | По умолчанию | Default |
| 1 | Без помощника | Without adviser |

Контекстные подсказки в углу экрана. Не влияет на симуляцию — только UI.

## Сложность компьютера

<a id="difficulty--сложность"></a>
### Сложность (`difficulty`)

| Значение | Множитель скорости | Русское название | Английское название |
| :---: | --- | --- | --- |
| 0 | 0.3 | Легко | Easy |
| 1 | 0.5 | Нормально | Normal |
| 2 | 0.75 | Сложно | Hard |
| 3 | 1.0 | Очень сложно | Very Hard |
| 4 | 1.25 | Невозможно | Impossible |

Сложность меняет скорость строительства и найма компьютерного игрока. Дополнительных стартовых ресурсов он не получает. Поведение компьютера разобрано в [`recon/systems/ai_behavior.md`](../../recon/systems/ai_behavior.md).
