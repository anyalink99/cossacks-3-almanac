# Максимальное число строителей

[← Таблицы и расчёты](../README.md)

У каждого здания есть предел крестьян, которые могут одновременно участвовать в строительстве или ремонте. Лишние рабочие не ускоряют процесс. Предел зависит от формы и размера здания, поэтому национальные варианты одной постройки иногда различаются.

Игра никогда не допускает больше **30** одновременных строителей. Расчёт ниже повторяет расстановку рабочих по периметру здания [^1]. Основные значения дополнительно проверены непосредственно в игре.

Ворота создаются мгновенным преобразованием выбранного сегмента стены. Указанный для них предел нужен только при ремонте.

Практическое время с разным числом рабочих приведено в [таблице строительства и ремонта](construction_times.md).
