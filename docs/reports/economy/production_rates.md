# Скорость производства юнитов

[← Таблицы и расчёты](../README.md)

Сколько юнитов в минуту даёт **одно здание**, при бесперебойной очереди, свободных мест населения и достаточных ресурсов.

**Как это работает** [^1]:
- У здания одна очередь; параллельно два юнита не производятся.
- Стоимость списывается при начале производства каждого юнита.
- Если нет свободных мест населения или достигнут лимит юнитов, производство останавливается.

Сгруппировано по нациям. Для каждого здания — список юнитов, которых оно может производить.

## Замечания

1. Каждый юнит занимает одно место населения. Городские центры, дома и казармы увеличивают доступный предел.
2. **Расход еды** показывает содержание юнита за игровую секунду.
3. **При нехватке мест населения производство останавливается:** юнит не выходит, а прогресс остаётся замороженным.
4. Несколько одинаковых зданий работают параллельно. Например, пять казарм дают примерно впятеро больше юнитов в минуту, чем одна.
