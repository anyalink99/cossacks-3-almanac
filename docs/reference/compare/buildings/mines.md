# Шахты

[← buildings/](README.md) · [← compare/](../README.md) · [← Index](../../README.md)

Шахты добывают `coal` / `gold` / `iron`. Скрипт случайно использует `commonsid+'X'` для всех cluster'ов (eur/rus/tur/ukr/sco), но статы — общие: парсер surface'ит только `eur*` версию, потому что все cluster'ы наследуют одинаковые HP/цену/rate. Cluster-специфичных шахт **нет** — это единая модель для всех наций.
