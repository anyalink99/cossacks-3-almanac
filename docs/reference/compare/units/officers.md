# Офицеры

[← units/](README.md) · [← compare/](../README.md) · [← Index](../../README.md)

Офицер — командир отряда (squad leader), нанимается в казармах. Пять национальных вариантов (`officer` / `officer18` / `officerrus` / `officersco` / `officertur`); статы заметно расходятся по стоимости, времени найма и урону.

> **Базовые значения** (мода по столбцу — что считается «обычным» в этом классе): HP = 125, Время (g-сек) = 10.0, F = 50, G = 200, I = 10, апкип G (raw) = 60, speed = 32, урон = 30, дальность (тайл.) = 1.22, перезарядка (с) = 0.0, пика = 2, меч = 2, пуля = 5, картечь = 200, стрела = 10, ядро = 30.
> **Жирным** в таблице ниже — отклонения от этих базовых значений. Так сразу видно, какой юнит «особенный» в каждой колонке.

> **Апкип**: `consume × 32 / 20000` за игр-секунду (raw consume — в скобках). **Speed**: единицы движка `t/g-сек × 50/1.5` (peasant=32, infantry=24, fasthorse=96, cannon≈22).
