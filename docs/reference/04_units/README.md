# Юниты

[← Краткий справочник](../README.md)

Все юниты сгруппированы по роли. Чтобы сопоставить похожие войска строка к строке, откройте [раздел сравнений](../compare/README.md).

## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Юнит** | Каноническое русское имя; внутренний код показан вторым |
| **Нации** | Список держав, имеющих этого юнита («все» = доступен почти всем нациям). |
| **Здоровье** | Очки здоровья при создании |
| **Время найма (игр. с)** | Время производства в игровых секундах. Чтобы получить реальное время на скорости «Быстро», разделите значение на 1,4. |
| **Е / З / Ж** | Цена за единицу: **еда / золото / железо**. Дерево, камень и уголь у юнитов почти всегда равны нулю, поэтому скрыты. |
| **урон** | `weapon.damage` основного оружия (см. ниже) — сырой урон одного выстрела или удара до вычета защиты цели. Полная формула — в главе [«Бой и движение»](../02_combat/README.md). |
| **дальн. (клетки)** | Радиус оружия в клетках (`weapon.radiusmax / 53.33`). 0 для рукопашных. |
| **Перезарядка** | Игровые секунды между выстрелами; у рукопашных темп задаётся анимацией удара |
| **пика / меч / пуля / картечь / стрела / ядро** | **Защита** юнита от соответствующего типа оружия (`prot_pike` / `prot_sword` / `prot_bullet` / `prot_cannister` / `prot_arrow` / `prot_cannonball`). Чем выше — тем меньше входящий урон. |

«—» в любой колонке = поле отсутствует у этого юнита (например, рукопашник не имеет дальности).

> **Какое оружие показано.** Если у юнита несколько видов оружия — например, у мушкетёра XVIII века есть штык и мушкет, а у пушки ядро и картечь, — в сводной строке показано самое дальнобойное. Поэтому таблица информативнее, чем простое чтение первого технического слота (`weapon[0]`), которым часто оказывается штык.
