# Здания

[← Краткий справочник](../README.md)

Часть зданий имеет отдельный вариант для каждой нации, а внешний вид остальных зависит от архитектурной группы. Каноническое название всегда показано первым; внутренний код рядом нужен только для точной сверки.

Цены ниже — для **первого** экземпляра. Цена N-го здания того же типа = базовая цена с учётом накопительного роста. Готовые таблицы для первых шести экземпляров находятся в разделе [«Цена следующих зданий»](../../reports/economy/scaling_prices.md).

## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Здание** | Каноническое название и внутренний код |
| **Нация / Нации** | Каким нациям доступно здание |
| **Здоровье** | Запас здоровья полностью построенного здания |
| **Время строительства** | В игровых секундах для одного строителя. Несколько крестьян сокращают его; подробности — в статье [«Строительство и ремонт»](../../recon/world/economy/building_mechanics.md). |
| **Рост цены** | Насколько дорожает каждый следующий экземпляр здания. 100% означает ту же цену, 300% — втрое дороже предыдущего. |
| **Еда / Дерево / Камень / Золото / Железо / Уголь** | Цена первого экземпляра |
| **Места населения** | Насколько здание увеличивает предел населения |
| **Производит** | Канонические названия создаваемых юнитов |
| **Особенности** | Оружие, вместимость, добыча и другие свойства |

**Жирным** в таблицах ниже — отклонения от базового значения (мода по столбцу), чтобы быстро видеть, чем нация отличается от большинства.

## Строительство и ремонт

Полный разбор стройки, ремонта, отмены и разрушения — в
[статье о строительстве и ремонте](../../recon/world/economy/building_mechanics.md).
Главные практические правила:

- Дополнительные строители ускоряют работу почти пропорционально своему числу,
  но вокруг каждого здания помещается ограниченное число крестьян.
- Недостроенное здание получает только треть обычной защиты и потому особенно
  уязвимо.
- Строящееся здание можно захватить, включая башню.
- Один крестьянин восстанавливает примерно 29 здоровья за игровую секунду.
- Отмена строительства или заказа возвращает всю уже списанную стоимость.
- При разрушении работающего здания оплаченные заказы из его очереди
  возвращаются владельцу.
