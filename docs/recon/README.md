# Как устроена игра

[← Главная энциклопедии](../README.md)

Этот раздел объясняет не только **сколько**, но и **почему**. Здесь разобраны
скрытые правила Cossacks 3: путь крестьянина до склада, выбор цели,
построения, захват зданий, очередь приказов, генерация карты и поведение
компьютерных игроков.

Статьи можно читать независимо. Канонические русские названия объектов
используются в тексте, а внутренние коды и имена функций оставлены в
примечаниях для точной проверки.
