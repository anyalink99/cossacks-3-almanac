# Special Infantry (18th century)

[← Unit Comparisons](README.md) · [← All Comparisons](../README.md) · [← Quick Reference](../../README.md)

These national eighteenth-century riflemen are trained alongside regular Musketeers: the Highlander for Scotland, Pandur for Austria, Szekely for Hungary, Chasseur for France, Volunteer for Portugal, and Jaeger for Switzerland. They are usually faster or deal distinctive damage, but tend to have less health.

> **Baseline values** are the most common values in each column for this class: health = 75, training time = 6.5 game seconds, food = 30, gold = 25, iron = 10, raw food upkeep = 39, speed = 32, damage = 20, range = 19.69 cells, and reload time = 5.94 seconds.
> **Bold** values in the table differ from that column's baseline.

> **Upkeep** is shown as resources per game second; the raw `consume` value is given in parentheses. **Speed** uses the engine's own scale, where a larger number means faster movement.
