# Special infantry (18th century)

[← units/](README.md) · [← compare/](../README.md) · [← Index](../../README.md)

Unique 18th century national marksmen, built in the same 18th century barracks as `musketeer18` - Highlander (sco), Pandur (aus), Szekely (hun), Chasseur (fra), Yeager (por/swi). An alternative to the basic musketeer: often faster or with special damage, but on average cheaper and weaker in HP.

> **Bold** in the table below indicates deviations from these basic values. This way you can immediately see which unit is “special” in each column.
