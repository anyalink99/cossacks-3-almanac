# Special infantry (18th century)

[← Unit Comparisons](README.md) · [← All Comparisons](../README.md) · [← Quick Reference](../../README.md)

Unique national riflemen of the 18th century, built in the same 18th century barracks as a regular musketeer: Highlander for Scotland, Pandur for Austria, Szekely for Hungary, Chasseur for France, Jaeger for Shipyard in Portugal and Switzerland. They are usually faster or deal special damage, but are inferior in health.

> **Base values** (column mode - what is considered "common" in this class): health = 75, recruitment time (game s) = 6.5, food = 30, gold = 25, iron = 10, food consumption (service value) = 39, speed = 32, damage = 20, range (tile) = 19.69, cooldown (s) = 5.94.
> **Bold** in the table below indicates deviations from these basic values. This way you can immediately see which unit is “special” in each column.

> **Content** is indicated in the resource per game second; the service value from the game files is given in parentheses. **Speed** is given in engine units: the higher the number, the faster the unit.
