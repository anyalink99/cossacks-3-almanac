# Stables

[← Building comparisons](README.md) · [← All comparisons](../README.md) · [← Quick reference](../../README.md)

> **Baseline values** are the most common values in each column: health = 20000, construction time = 625.0 game seconds, price growth = 200%, wood = 2500, stone = 100, gold = 600, population = 0.
