# Cossacks 3 — Цены зданий по N-му экземпляру

**Производный** файл (расчётный, не извлечение). Считается из `output/data.json` скриптом [`parser/compute_scaling.py`](../../../parser/compute_scaling.py).

## Формула

Источник: [`unit.script:5650-5689`](<C:/Program Files (x86)/Steam/steamapps/common/Cossacks 3/data/scripts/lib/unit.script>) функция `_unit_GetCostByID`.

```
costmodifier   = pow(costpercent / 100, count)         // count = уже у игрока
final_price[r] = floor(base_price[r] * costmodifier)   // отдельно для F/W/S/G/I/C
```

Где `count` — это `gPlayer[plInd].counter.all[cid][unitID]`. Счётчик инкрементируется при создании ([`unit.script:3847`]) и **декрементируется** при разрушении ([`unit.script:3969`]) — снесли центр, следующий снова дешевле.

## Особые случаи

- `costpercent = 0` или `100` → масштабирования нет, цена постоянная.
- Для **наёмников** (`bmercenary=True`) счётчик объединяется с парным юнитом (`archerdip ↔ archerturdip`, `dragoon18dip ↔ lightcavalrydip`), и модификатор ограничен сверху значением **×2**. В этой таблице наёмников нет — только здания.
- Для не-наёмников модификатор ограничен сверху значением **×20000**. На N≤6 этот предел никогда не срабатывает (даже у казарм с `costpercent=500`: 5⁵ = 3125 < 20000).
- **Округление вниз (floor)** для каждого ресурса независимо. Для дорогих зданий с `costpercent=104` это даёт ступенчатый рост, а не плавный.

## Колонки N=1..6

`N=1` — стоимость **первого** экземпляра (count=0, модификатор=1, цена = базовая). `N=2` — второго (count=1) и т.д. Каждая ячейка — суммарная стоимость в формате `F<food> W<wood> S<stone> G<gold> I<iron> C<coal>` (нулевые ресурсы скрыты).
