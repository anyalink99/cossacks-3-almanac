# Глоссарий извлечённых полей игры

[← Техническая документация](../README.md)

Здесь собраны технические поля, встречающиеся в `data.json`, скриптах игры и
генерируемых отчётах. В читательской документации вместо них используются
обычные русские игровые термины.

## Идентификация объектов

| Поле | Значение |
|---|---|
| `sid` | Устойчивый внутренний идентификатор объекта из `unit.script`, например `bavcen` или `peaaus`. |
| `cid` | Числовой идентификатор нации. |
| `usage` / `usage_short` | Роль объекта, используемая ИИ и игровыми формулами. |
| `commonsid` / `cluster` | Архитектурная группа общих зданий. |
| `costpercent` | Множитель цены каждого следующего здания того же типа. |
| `farm` | Прибавка к пределу населения. |

## Экономика

| Поле | Значение |
|---|---|
| `resefficiency[cid][restype]` | Текущая эффективность добычи ресурса в процентах. |
| `consume[restype]` | Периодическое потребление ресурса, отдельное от цены строительства или найма. |
| `peasantabsorber` | Число крестьян, которые могут работать внутри здания. |
| `produce[restype]` | Доход ресурса на одного работника внутри производящего здания. |
| `fieldlife` | Модификатор прочности поля. |

## Боевые поля и флаги состояния

| Поле | Значение |
|---|---|
| `bbuilt` | Завершено ли строительство. Недостроенное здание получает только треть обычного значения щита. |
| `bcapture` | Можно ли захватить объект. |
| `bnohungry` | Освобождён ли объект от потребления еды и потерь при голоде. |
| `bmercenary` | Флаг наёмника, используемый содержанием в золоте и механикой бунта. |
| `bfamine` | Состояние голода у игрока. |
| `brebellion` | Состояние бунта наёмников у игрока. |
| `brised` | Доступен ли ресурсный объект для добычи. |
| `uniqrnd` | Детерминированное случайное число объекта в диапазоне `[0, 1)`. |
| `gc_obj_weapon_kind_*` | Тип оружия, выбирающий показатель защиты цели. |

## Пересчёт времени

| Поле | Значение |
|---|---|
| `gc_time_to_frames = 32` | Число кадров симуляции в одной игровой секунде. |
| `gc_buildtime_modifier = 10` | Дополнительный множитель только для времени строительства зданий. |
| `slow / normal / fast = 7 / 10 / 14` | Уровни скорости симуляции. На скорости «Быстро» игровая секунда длится около 0,71 реальной секунды. |
