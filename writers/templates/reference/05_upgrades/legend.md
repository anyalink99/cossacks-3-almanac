Внутренний код после названия нужен только для точной сверки с файлами игры.
Обычному читателю достаточно канонического названия, эффекта, цены и времени
исследования.

## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Улучшение** | Каноническое название и внутренний код. |
| **Нации** | Список наций; «все» — если улучшение применимо почти ко всем. Национальный вариант с другим значением показывается отдельной строкой. |
| **Эффект** | Что изменяет улучшение: урон, защита, скорость добычи, время строительства и т. п. |
| **Значение** | Числовая величина эффекта. Для процентных эффектов 50 означает +50%. Особые служебные масштабы уже пояснены в названии или примечании. |
| **Еда / Дерево / Камень / Золото / Железо / Уголь** | Цена исследования. |
| **Время** | Время исследования в игровых секундах. Пока оно идёт, здание занято. |

> **Как читать таблицы ниже.** В каждой секции одна строка = одно
> улучшение для одной нации. Если значение одинаковое у всех 21 наций,
> вместо списка стоит «все» (одна строка). Если у нации
> другие цена или эффект, она показана отдельной строкой.
