**Структура `sid`:**

- `<nat><place>.<unit>.<itype>.<level>` — апгрейд по конкретному юниту в
  кузнице, конюшне или казарме (например, `auspolbla.pikeman.1.3` =
  Австрия → кузница → пикинёр → урон → уровень 3).
- `<nat><place>.<level>` — один на нацию: в академии, мельнице или
  ратуше (например, `auaca.4` = Австрия → академия → апгрейд №4
  «field melioration»).
- `<cluster><place>.<level>` — общий для кластера наций (например,
  `eurtow.1` для всех eur-наций).
- `eurgol.N` / `euriro.N` / `eurcoa.N` — апгрейды шахт (одинаковы для
  всех наций).

## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Апгрейд** | Локализованное имя + `sid`. |
| **Нации** | Список наций; `all` — если апгрейд применим хотя бы к 18 нациям. Если у одной из наций своё значение через `_country_ModifyUpgrade` — она в отдельной строке. |
| **itype** | Тип эффекта в человеческих терминах (расшифровка `gc_upg_type_*`): `+damage`, `+damage %`, `+protection`, `+food eff %`, `price %`, `build time %`, `enable unit`, `+shield` и т. д. |
| **val** | Значение эффекта. Семантика зависит от `itype`: для процентных = просто число (50 значит +50%, **−7500000 в `aca.10` = −75% buildtime — особый scale в скрипте, делитель × 10⁵**); для `+damage` / `+shield` = единицы. |
| **F / W / S / G / I / C** | Цена исследования: **Food / Wood / Stone / Gold / Iron / Coal**. |
| **Время** | `time` в игровых секундах. Здание занято исследованием на это время. |

> **Как читать таблицы ниже.** В каждой секции одна строка = один
> апгрейд для одной нации. Если значение одинаковое у всех 21 наций,
> вместо списка стоит `all` (одна строка). Если у нации
> переопределение через `_country_ModifyUpgrade` — она оформлена
> отдельной строкой.
