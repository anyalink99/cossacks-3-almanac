# 07. Морской флот

[← Index](README.md)

> **Главное:**
>
> - **Один Порт = всё море.** Постройка Порта (`<cluster>por`) разблокирует весь морской ростер: 6 типов кораблей + Транспорт + Рыбачья лодка. Других зданий, производящих корабли, в игре нет.
> - **Корабли заметно дороже сухопутных юнитов**, но и значительно прочнее (HP 25 000–90 000 против ~50–380 у пехоты и кавалерии). Линейный корабль — плавучий бункер с самым высоким DPS в игре.
> - **Транспорт** — единственный способ перевезти пехоту через воду. Вместимость — 120 «слотов».
> - **Рыбачья лодка — единственный морской источник food.** Альтернатива полям и охоте на ранней стадии у морских наций.

## Порт (`<cluster>por`)

Параметры Порта определяются в одной ветке `commonsid+'por'`-разбора [^n1].

| Параметр | Значение |
|---|---:|
| HP | **50 000** |
| `buildtime` | 5000 frames = **1562.5 g-сек** (≈ 1116 real-сек @ fast = 18.6 мин для одного строителя) |
| `costpercent` | **150** (каждый следующий +50 %) |
| Цена | 1600 W / 800 S / 400 I |
| Prereq | `<cluster>mar` (рынок) |
| `bcapture` | `False` — захвату не подлежит, только разрушение |
| `vision` | 3 (32 t FOW) |

**Производит:** `battleship`, `chaika` / `yacht` / `yachttur`, `ferry`, `fishboat`, `frigate` / `xebec`, `galley`. Порт у всех наций один и тот же — нация-специфичных Портов с разным ростером нет (только `chaika` ↔ `yacht` ↔ `yachttur` подменяют друг друга по нации).

**Стоимость второго Порта:** `1600 × 1.5 = 2400 W` + `800 × 1.5 = 1200 S` + `400 × 1.5 = 600 I` (правило `costpercent` см. в [01_economy/README.md](../01_economy/README.md)). Третий: 3600 / 1800 / 900.

## Транспорт (`ferry`)

{ferry_block}

**Что значит `transport = 120`:** один Транспорт вмещает до **120 единиц population** (слотов фермы). Большинство пехоты занимает 1 слот, кавалерия — 2–3, артиллерия — 5+. Поэтому Транспорт перевозит примерно 100 мушкетёров или 40 рейтаров.

Подробности (поведение при погрузке, уязвимость, эскорт) — в [`../../recon/world/combat/naval_combat.md` §4](../../recon/world/combat/naval_combat.md).
