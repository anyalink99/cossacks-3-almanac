# Сравнения

[← Index](../README.md)

Параллельные таблицы юнитов одного класса по всем нациям. Помогает выбирать пика-против-пики, стрельца-против-стрельца и т.д. Базовые значения (мода по столбцу) указаны прямо над таблицей в каждом файле — отклонения выделены **жирным**, чтобы было видно, чем нация отличается от большинства.
