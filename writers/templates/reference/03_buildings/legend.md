## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Здание** | Каноническое название и внутренний код |
| **Нация / Нации** | Каким нациям доступно здание |
| **Здоровье** | Запас здоровья полностью построенного здания |
| **Время строительства** | В игровых секундах для одного строителя. Несколько крестьян сокращают его; подробности — в статье [«Строительство и ремонт»](../../recon/world/economy/building_mechanics.md). |
| **Рост цены** | Насколько дорожает каждый следующий экземпляр здания. 100% означает ту же цену, 300% — втрое дороже предыдущего. |
| **Еда / Дерево / Камень / Золото / Железо / Уголь** | Цена первого экземпляра |
| **Места населения** | Насколько здание увеличивает предел населения |
| **Производит** | Канонические названия создаваемых юнитов |
| **Особенности** | Оружие, вместимость, добыча и другие свойства |

**Жирным** в таблицах ниже — отклонения от базового значения (мода по столбцу), чтобы быстро видеть, чем нация отличается от большинства.
