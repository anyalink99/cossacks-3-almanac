## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Юнит** | Локализованное имя + `sid` (внутренний идентификатор из `unit.script`) |
| **нации** | Список наций, имеющих этого юнита (`all` = доступен всем) |
| **HP** | Очки здоровья при создании |
| **Время (g-сек)** | `buildtime` в игровых секундах (1 game-сек = 32 кадра; для real-сек @ fast делите на 1.4) |
| **F / G / I** | Цена за единицу: **Food / Gold / Iron**. Wood/Stone/Coal у юнитов почти всегда = 0, потому скрыты. |
| **урон** | `weapon.damage` основного оружия (см. ниже) — сырой урон одного выстрела/удара ДО вычета защиты цели. Полная формула — в [02_combat/README.md](../02_combat/README.md). |
| **дальн. (тайл.)** | Радиус оружия в тайлах (`weapon.radiusmax / 53.33`). 0 для рукопашных. |
| **перезарядка** | `weapon.pause` в секундах между выстрелами (0 для рукопашных — там темп задаётся анимацией). |
| **пика / меч / пуля / картечь / стрела / ядро** | **Защита** юнита от соответствующего типа оружия (`prot_pike` / `prot_sword` / `prot_bullet` / `prot_cannister` / `prot_arrow` / `prot_cannonball`). Чем выше — тем меньше входящий урон. |

«—» в любой колонке = поле отсутствует у этого юнита (например, рукопашник не имеет дальности).

> **Какое оружие показано.** У юнитов с несколькими weapon-слотами (musketeer18 = штык + мушкет; гренадёр = штык + мушкет + граната; cannon = ядро + картечь) выбирается оружие с максимальной дальностью. Это даёт более информативную картину, чем weapon[0], которое часто = ближний штык.
