**Структура `sid`:**

- `<nat><place>.<unit>.<itype>.<level>` — поюнитный апгрейд в кузнице/конюшне/бараке (например `auspolbla.pikeman.1.3` = Австрия → кузница → пикинёр → урон → уровень 3).
- `<nat><place>.<level>` — один на нацию, в академии/мельнице/ратуше (например `auaca.4` = Австрия → академия → апгрейд №4 «field melioration»).
- `<cluster><place>.<level>` — общие для кластера наций (например `eurtow.1` для всех eur-наций).
- `eurgol.N` / `euriro.N` / `eurcoa.N` — апгрейды шахт (одинаковы для всех наций).

## Расшифровка колонок

| Колонка | Значение |
|---|---|
| **Апгрейд** | Локализованное имя + `sid` |
| **нации** | Список наций (или `all` если применимо ≥18). Если у нации своё значение через `_country_ModifyUpgrade` — она в отдельной строке. |
| **itype** | Тип эффекта в человеческих терминах (расшифровка `gc_upg_type_*`): `+damage`, `+damage %`, `+protection`, `+food eff %`, `price %`, `build time %`, `enable unit`, `+shield`, … |
| **val** | Значение эффекта. Семантика зависит от `itype`: для процентных = просто число (50 значит +50%, **−7500000 в `aca.10` = −75% buildtime — деление на 10⁵ ломает scale в скрипте**), для +damage / +shield = единицы. |
| **F / W / S / G / I / C** | Цена исследования: **Food / Wood / Stone / Gold / Iron / Coal**. |
| **время** | `time` в игровых секундах. Здание занято исследованием на это время. |
