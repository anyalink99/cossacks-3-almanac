# Cossacks 3 — Тренажёр стратегий (v0.4)

[English](README.en.md) · **Русский**

> **Статус: работает.** Редактор загружает игровые данные, строит порядок
> развития на шкале времени и запускает экономическую симуляцию прямо в
> браузере.

Инструмент предназначен для проверки порядка строительства и производства:
когда хватит ресурсов, сколько крестьян можно выделить, когда освободится
здание и какие требования ещё не выполнены.

## Что умеет

- показывает доступные здания, юниты и улучшения для выбранной нации;
- добавляет строительство, обучение, исследования, торговлю и распределение
  крестьян на общую шкалу времени;
- позволяет перетаскивать действия по времени и редактировать их параметры
  через инспектор;
- учитывает требования дерева развития, занятость производящих зданий,
  ресурсы, население и предел строителей;
- поддерживает конечное и бесконечное производство;
- показывает графики ресурсов, населения и ход симуляции;
- сохраняет планы в браузере, импортирует и экспортирует JSON;
- умеет брать распознанный порядок действий из реплея;
- работает на русском и английском языках.

## Как запустить

В корне репозитория:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/editor/`. Через `file://` инструмент не
работает: браузер блокирует загрузку данных и модулей.

При первом открытии загружаются Pyodide и Chart.js; последующие открытия
обычно используют браузерный кеш.

Экономику считает та же функция
`simulator/simulate_economy.py:simulate_in_memory`, что используется в
командной строке.

## Границы инструмента

Сейчас здесь нет отдельного режима сравнения двух планов, графического дерева
развития и пространственной карты. Эти возможности не нужны для основной
задачи редактора и могут быть добавлены отдельно.

## Сверка с командной строкой

Чтобы сравнить результат с консольным симулятором, передайте экспортированный
JSON в:

```bash
python simulator/simulate_economy.py <plan.json>
```

Числа в отчёте и в браузерном редакторе должны совпасть.
